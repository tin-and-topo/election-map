Security and privacy

A public guide that keeps personal data out.

VoteReady is designed as a static public-information website. It does not provide accounts, forms, analytics, address lookups, cookies, or local storage.

What this site does not collect

The site does not ask for, transmit, or save names, addresses, voter-registration records, device identifiers, or voting choices. Selecting a district changes only the page view; the optional district name in the URL is never sent to a server.

How the public site is protected

The application has no third-party scripts or packages and applies a restrictive browser content policy to block unapproved connections, embedded content, and form submissions. It uses HTTPS through GitHub Pages.

Limits of a static website

Do not submit sensitive information into a future version of this website unless a privacy-reviewed, secure backend has been approved. Client-side code and every file in this public repository are visible to everyone.
